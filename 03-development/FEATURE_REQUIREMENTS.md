# 기능 요구사항 (Feature Requirements)

## 📋 설문 생성 개선 아이디어

### 1. 참고 자료 업로드 기능
**현재 문제**: AI가 목적과 대상만으로 설문을 생성하면 구체성이 부족할 수 있음

**개선 방안**:
- **파일 업로드**: PDF, DOC, TXT 등 참고 문서 업로드
- **이미지 업로드**: 제품 스크린샷, 와이어프레임, 디자인 시안
- **URL 입력**: 웹사이트, 경쟁사 분석 자료, 기존 설문 링크
- **텍스트 입력**: 상세한 배경 정보, 요구사항, 가설 등

### 2. 컨텍스트 제공 인터페이스
```
설문 생성 폼 구조:
┌─────────────────────────────────────┐
│ 기본 정보                            │
│ - 목적: [텍스트 입력]                │
│ - 대상: [텍스트 입력]                │
│ - 언어: [선택]                       │
├─────────────────────────────────────┤
│ 참고 자료 (새로 추가)                │
│ - 파일 업로드: [드래그앤드롭]        │
│ - 이미지 업로드: [이미지 첨부]       │
│ - 관련 URL: [URL 입력]              │
│ - 상세 설명: [긴 텍스트 입력]        │
├─────────────────────────────────────┤
│ AI 설정                             │
│ - 엔진 선택: [Claude/Ollama]        │
│ - 모델 선택: [드롭다운]              │
└─────────────────────────────────────┘
```

### 4. 기술적 구현 방안

#### 백엔드 확장
```javascript
// 새로운 API 엔드포인트
POST /api/surveys/generate-advanced
{
  "basic": {
    "purpose": "string",
    "targetAudience": "string", 
    "language": "ko|en"
  },
  "context": {
    "files": ["파일ID들"],
    "images": ["이미지ID들"],
    "urls": ["URL들"],
    "description": "상세 설명",
    "painPoints": ["현재 문제점들"],
    "goals": ["개선 목표들"],
    "competitors": ["경쟁사 정보"]
  },
  "settings": {
    "engine": "claude-code|ollama",
    "model": "string",
    "questionCount": "number",
    "complexity": "basic|intermediate|advanced"
  }
}
```

#### 파일 처리 서비스
```javascript
// 새로 추가될 서비스
- fileUploadService.js    // 파일 업로드 및 텍스트 추출
- imageAnalysisService.js // 이미지 분석 (OCR, 객체 인식)
- urlScrapingService.js   // 웹페이지 콘텐츠 추출
- contextAnalysisService.js // 컨텍스트 종합 분석
```

#### 프론트엔드 컴포넌트
```typescript
// 새로 추가될 컴포넌트
- FileUploadZone.tsx      // 드래그앤드롭 파일 업로드
- ImagePreview.tsx        // 이미지 미리보기 및 편집
- ContextEditor.tsx       // 풍부한 텍스트 편집기
- AdvancedSettings.tsx    // 고급 설정 패널
- ProgressIndicator.tsx   // 생성 진행 상황 표시
```

### 6. 예상 효과

#### 설문 품질 향상
- **구체성**: 일반적 → 도메인 특화 질문
- **관련성**: 추상적 → 실제 사용자 경험 기반
- **실행가능성**: 모호한 → 구체적 개선 방향 제시

#### 사용자 경험 개선
- **효율성**: 설문 작성 시간 80% 단축
- **정확성**: 설문 재작업 필요성 70% 감소
- **만족도**: 더 유용한 인사이트 도출

#### 비즈니스 임팩트 (원익IPS)
- **고객 만족도**: 더 정확한 고객 니즈 파악
- **개발 효율성**: 구체적 개선 방향으로 개발 시간 단축
- **경쟁력**: 고객 중심 제품 개발로 시장 우위 확보

### 7. 구현 우선순위

#### 높음 (Phase 12-15)
1. **상세 설명 입력**: 가장 기본적이고 효과적
2. **URL 스크래핑**: 경쟁사 분석 등에 즉시 활용 가능
3. **텍스트 파일 업로드**: 기존 자료 활용

#### 중간 (Phase 20-25)  
1. **이미지 업로드**: UI/UX 설문에 매우 유용
2. **PDF 처리**: 업무 문서 활용도 높음
3. **드래그앤드롭**: 사용성 크게 개선

#### 낮음 (Phase 30+)
1. **고급 AI 분석**: 기본 기능 안정화 후
2. **자동 데이터 수집**: 법적/기술적 검토 필요
3. **고급 검증**: 완성도 높은 버전에서

## 💡 핵심 인사이트

> "좋은 설문은 좋은 질문에서 나오고, 좋은 질문은 충분한 맥락에서 나온다."

현재 AI 설문 생성은 "목적 + 대상"만으로 질문을 만들지만,
실제로는 **"배경 + 현재 상황 + 문제점 + 목표 + 제약사항"** 등의 
풍부한 컨텍스트가 있어야 의미있는 설문이 생성됩니다.

이 기능이 구현되면 우리 서비스는 단순한 "AI 설문 생성기"가 아닌
**"맥락적 인사이트 도출 플랫폼"**으로 진화할 수 있습니다.
